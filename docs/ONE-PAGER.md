# Constellation: the one-page version

Working name. Details: [`EXPLAINER.md`](EXPLAINER.md) (plain words) and [`PITCH.md`](PITCH.md) (technical).

**The idea.** In a multiworld randomizer, friends play different video games at once, and the treasure you find in your game is secretly swapped into a friend's game. It is a team puzzle that runs for days.

**Where it is today.** A free, volunteer-built project called Archipelago runs this for around 80 games, and the item-mixing works well. Getting started is the hard part: hand-written settings files, a patch file for your own game copy, typed server addresses and port numbers, a different helper program for each game, and no word on what happened while you were away.

**What we're building.** The easy front door to the same games.
- **Players:** open a link, pick settings inside the game, press Connect. An inbox tells you what you got and when someone finds your item.
- **Hosts:** one screen to see who's online and fix problems, shareable seeds, a real race mode.
- **Game makers:** a small toolkit and a simple format to add a game, plus a way to test it.
- **Compatible:** existing Archipelago games and programs work from day one.

**How we make money.** We charge for the service, never for game files.
1. Game studios pay for an official, supported integration built in during development. The earliest income.
2. Bigger, private or longer-lasting rooms.
3. Phone and Discord alerts.
4. Tools for streamers and event runners.

Small public games stay free.

**Biggest risks.** Game publishers could object to a business around fan games, so we keep paid products to services and studio deals and we will get a lawyer's advice first. Community goodwill matters, so we stay compatible and give credit. All of this is still to be measured: prices, player numbers, team and funding.

**First step.** A new server where an existing Archipelago program connects with a simple link instead of a port number.
